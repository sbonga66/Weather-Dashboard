# Weather Dashboard
A responsive web-based weather dashboard that allows users to search for weather information for different locations.

## Features
* Search for weather by city
* Display current weather information
* Display temperature and weather conditions
* Responsive design for desktop and mobile devices
* User-friendly interface
* Weather data retrieved through an API
* JavaScript-based dynamic content

## Technologies Used
* HTML5
* CSS3
* JavaScript
* REST API
* Local Storage
* Git
* GitHub

## Skills Demonstrated
* Front-end web development
* JavaScript programming
* API integration
* DOM manipulation
* Local Storage
* Responsive web design
* Git and GitHub
